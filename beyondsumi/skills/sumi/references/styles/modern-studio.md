# Modern Studio Tech
Visual identity for high-density explainers and tech breakdowns.

## Visual Theme
Pure white high-key studio, subtle light-gray perspective grid, glowing cyan/blue glass UI.

## Character DNA
Minimalist 2D animated stick figure wearing a bright red beanie (smooth rounded knit, no pom-pom) and a yellow t-shirt, with simple black stick limbs and shorts. Simple black lines, vibrant colors, smooth 2D animation style.

## Environment Specification
In a modern bright white studio space with subtle light-gray perspective grid lines on the floor plane. High-key studio lighting, clean white negative space, sleek glowing cyan and electric blue glass holographic UI elements.

## Negative Constraints
Strictly minimalist studio aesthetic, no circuit board textures, no sci-fi wall panels, no spaceship corridors, no cracked concrete, no grunge textures, no photorealistic human skin, no speech bubbles, no dialogue text boxes.
